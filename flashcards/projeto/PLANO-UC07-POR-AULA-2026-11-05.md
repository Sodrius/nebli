## Para que servem os integradores

Servem para recuperar a relação que os cards isolados não cobram: reconstruir uma organização, percorrer uma sequência, distinguir vizinhos pelo mesmo critério ou relacionar anatomia, função e consequência. O ganho deve ser nomeável. Saber identificar duas estruturas separadas não garante conseguir relacioná-las; mas repetir suas definições em outro card não cria integração.

Continuam sendo cards curtos no padrão que já funciona no NEBLI. Não são questões discursivas longas, resumos de aula ou um novo tipo de nota. Podem ser mecanismos, comparações, bases clínicas ou fatos situados, conforme a operação de recuperação.

## Como aparecem na sequência

Um organizador de conjunto entra quando a aula apresenta o conjunto, antes de seus detalhes. Uma integração causal/clínica entra depois dos fundamentos necessários. Uma relação entre aulas entra no primeiro ponto em que é usada, com contexto suficiente para revisão aleatória.

Assim, a sequência pode ser: situar região → organizador dos componentes → identificações e relações específicas → integração funcional/clínica. Não obrigar todas as aulas a uma sequência artificial nem agrupar integradores num deck separado.

Um integrador tem uma operação principal. Conjuntos recuperados juntos ou contrastes complementares usam o mesmo índice cloze como padrão. Índices distintos só para recuperações independentes, com cada irmão lido para excluir respostas vazadas. Não dividir automaticamente cada linha em um card. Se o percurso inteiro ficar longo, organizar por subpercursos anatômicos reais, mantendo a relação global recuperável.
