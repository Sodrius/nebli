# Flashcards NEBLI — mapa do diretório

Para decks médicos, a entrada única é [projeto/README.md](projeto/README.md): [MEMORY](../MEMORY.md), [FEEDBACKS](projeto/FEEDBACKS.md) e [EXECUCAO-DECK-AULA](projeto/EXECUCAO-DECK-AULA.md). Esta rota também vale para mensagem comum. Não usar antigos guias de julho/agosto como política vigente.

- `projeto/`: critérios encaminhados ao MEMORY, roteiro, fontes, fila UC08 e evidência da calibração de setembro.
- `scripts/`, `curadoria/`, `cards-nebli/`, `deck-cards/`, `decks-apkg/`: código, dados e entregas de épocas distintas. A existência de script, contrato ou pacote não autoriza executá-lo/reimportá-lo como pipeline atual.
- Dossiês AnKing, pesquisas e exemplares: referências sob consulta, com escopo/data. Exemplos não definem quota nem se tornam aprovação do conteúdo de outra aula; instruções antigas de produção foram marcadas como históricas.
- `etimologia/`: projeto separado; suas regras não governam cards de aulas médicas.

Feedback e preferências não se acumulam neste índice ou em novas rubricas: registrar no FEEDBACKS comum e atualizar MEMORY em seu lugar. Preservar fontes, scripts, dados autorais e trabalho concorrente. Arquivos de execução pertencem à corrida em `arquivos-trabalho/`, não a novos documentos de política.
