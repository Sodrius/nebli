## Enunciado

Explique a afirmação categórica: "uma oscilação do potencial de membrana que dependa de canais para íons dependentes de voltagem — Na, e K, com cinéticas de abertura diferentes — é necessariamente uma resposta tudo-ou-nada, isto é, uma onda inalterável dentro de condições fisiológicas"

## Justificativa esperada

A resposta tudo-ou-nada (all-or-none) ocorre porque:
1. Os canais para Na+ abrem rapidamente, causando despolarização rápida
2. Os canais para K+ abrem com cinética mais lenta, permitindo repolarização
3. Uma vez atingido o limiar, o potencial de ação propaga-se integralmente
4. A amplitude não varia com a intensidade do estímulo acima do limiar
5. É inalterável porque as propriedades cinéticas dos canais são determinadas geneticamente
