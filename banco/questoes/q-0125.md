## Enunciado

Um dado fenótipo celular dispara potenciais de ação nos quais a velocidade de despolarização é elevada (rápido aumento do potencial), mas a repolarização é lenta, formando-se um platô. A célula recupera o potencial de repouso após 250 ms. Uma das alternativas não explica este tipo de resposta. Assinale-a. A hipótese correta, entre as alternativas possíveis dependeria de outros experimentos.

## Alternativas

(A) A inativação dos canais para Na+ nesta célula é muito lenta

(B) A ativação dos canais para K+ é muito lenta

(C) Outros canais dependentes de voltagem para Ca2+ intervêm prolongando a despolarização

(D) O potencial de ação depende para a despolarização completamente de canais para Ca2+ de tipo L, cuja probabilidade de abertura aumenta quando a célula é muito despolarizada. Está célula não expressa canais para Na+ dependentes de voltagem

(E) A densidade dos canais para K+ dependentes de voltagem nestas células é baixa

## Gabarito

B

## Justificativa

Fenótipo observado: despolarização RÁPIDA (não lenta) → descarta D (só Ca2+ é lento). Depois platô (despolarização sustentada) + repolarização lenta. (A) inativação lenta de Na+ permitiria que Na+ continuasse entrando → sustentaria despolarização. (C) canais Ca2+ L abrem em potenciais positivos → corrente inward adicional → platô. (E) densidade baixa de K+ → menos repolarização. (B) ativação lenta de K+ explica repolarização lenta, mas não explica a despolarização rápida inicial.

## Conceitos-chave

- Potencial de ação com platô (células cardíacas)
- Papel de Ca2+ L na fase de platô
- Inativação de Na+ vs ativação de K+
