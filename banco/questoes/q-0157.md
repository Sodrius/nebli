## Enunciado

Seja o seguinte trecho do ciclo de Krebs:

```
A (2-cetoglutarato) → B → C → D (Oxaloacetato)
```

Considerando que o transporte de elétrons, a fosforilação oxidativa e o ciclo de Krebs estão funcionando normalmente, indique:

a) Os nomes dos intermediários A, B, C e D.

b) As enzimas responsáveis pelas transformações (A→B, B→C, C→D).

c) Os produtos secundários de cada etapa (cofatores reduzidos, ATP, GTP, etc).

## Gabarito

**a) Nomes dos intermediários:**
- **A: 2-Cetoglutarato (α-cetoglutarato)** ✓ (dado no problema)
- **B: Succinato** (após descarboxilação e redução)
- **C: Fumarato** (ácido fumárico)
- **D: Oxaloacetato** (malato) ✓ (dado no problema)

*Correto: A→B→C→D = 2-cetoglutarato → Succinata → Fumarato → Malato → Oxaloacetato*

**b) Enzimas e transformações:**

1. **A→B (2-Cetoglutarato → Succinata):**
   - Enzima: **Complexo 2-Cetoglutarato desidrogenase**
   - Cofatores: NAD⁺, Coenzima A

2. **B→C (Succinato → Fumarato):**
   - Enzima: **Succinato desidrogenase** (Complexo II da cadeia respiratória)
   - Cofator: FAD

3. **C→D (Fumarato → Malato → Oxaloacetato):**
   - Enzimas: **Fumarase** (Fumarato → Malato) + **Malato desidrogenase** (Malato → Oxaloacetato)
   - Cofator: NAD⁺

**c) Produtos secundários:**

1. **A→B**: 1 NADH + H⁺ + CO₂ + CoA-SH
2. **B→C**: 1 FADH₂
3. **C→D (via Malato)**: 1 NADH + H⁺
