## Enunciado

Animais de laboratório foram submetidos a dietas compostas exclusivamente de [glicose / ácido graxo / proteína]. Verificar se é possível sintetizar:

a) Ácido graxo a partir de glicose
b) Proteína a partir de glicose
c) Glicose a partir de ácido graxo
d) Proteína a partir de ácido graxo
e) Glicose a partir de proteína
f) Ácido graxo a partir de proteína

Justificar suas respostas aos itens de a a f, indicando:
- quando a síntese for possível, a via ou rota utilizada
- quando a síntese não for possível, a razão da impossibilidade

## Gabarito

**a) Ácido graxo a partir de glicose: SIM**
- Via: Glicose → Piruvato → Acetil-CoA → Malonil-CoA → Ácido graxo (síntese de ácidos graxos)
- Locação: Fígado e tecido adiposo

**b) Proteína a partir de glicose: PARCIALMENTE**
- Via: Glicose → Piruvato → Esqueletos carbônicos de aminoácidos não-essenciais
- Limitação: Glicose não fornece nitrogênio; seria necessária uma fonte de N (ex: glutamina)

**c) Glicose a partir de ácido graxo: NÃO**
- Razão: Ácidos graxos são degradados a Acetil-CoA. A carboxilação de Piruvato produzida por Acetil-CoA só regenera Acetil-CoA; não há perda líquida de carbono para formar glicose
- A reação chave: Acetil-CoA não pode ser convertido em Piruvato de forma líquida (ciclo de Krebs não regenera Piruvato)

**d) Proteína a partir de ácido graxo: PARCIALMENTE**
- Via: Ácido graxo → Acetil-CoA → esqueletos carbônicos de aminoácidos não-essenciais via oxaloacetato
- Limitação: Novamente, falta nitrogênio

**e) Glicose a partir de proteína: SIM**
- Via: Proteína → Aminoácidos → Piruvato (via transaminação/desaminação) → Glicose (gluconeogênese)
- Enzima chave: Glicogênio sintase catalisadora de Piruvato → Oxaloacetato

**f) Ácido graxo a partir de proteína: SIM**
- Via: Proteína → Aminoácidos com esqueleto de piruvato → Acetil-CoA → Síntese de ácidos graxos
- Exemplo: Aminoácidos glicogênicos (Ala, Ser, Gly, etc.) → Piruvato → Acetil-CoA
