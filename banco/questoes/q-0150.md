## Enunciado

Os processos são sempre espontâneos, independente da temperatura, quando:

## Alternativas

(A) ΔH > 0 e ΔS < 0

(B) ΔH < 0 e ΔS < 0

(C) ΔH > 0 e ΔS > 0

(D) ΔH < 0 e ΔS > 0

(E) Nenhuma está correta, pois a temperatura deve sempre ser levada em consideração.

## Gabarito

D

## Justificativa

A equação de Gibbs é: **ΔG = ΔH - T·ΔS**

Uma reação é espontânea quando ΔG < 0. Para que seja SEMPRE espontânea, independente de T:

Analisando cada alternativa:
- (A) ΔH > 0, ΔS < 0 → ΔG = (+) - T·(-) = (+) + (+) sempre positivo → **nunca espontânea**
- (B) ΔH < 0, ΔS < 0 → ΔG = (-) - T·(-) = (-) + (+) → depende de T (espontânea em T baixa)
- (C) ΔH > 0, ΔS > 0 → ΔG = (+) - T·(+) → depende de T (espontânea em T alta)
- **(D) ΔH < 0, ΔS > 0** → ΔG = (-) - T·(+) = (-) + (-) **sempre negativo** → **SEMPRE espontânea**, independente de T
- (E) Falso, pois a opção D está correta

**Resposta: D**
