## Enunciado

Um dado fenotípico celular dispara potenciais de ação nos quais a velocidade de despolarização é é elevada (rápido aumento do potencial), mas a repolarização é lenta, formando-se um platô. A célula recupera o potencial de repouso após 250 ms. Uma das alternativas não explica este tipo de resposta. Assinale-a. A hipótese correta, entre as alternativas possíveis dependerá de outros experimentos.

## Alternativas

a) A inativação dos canais para Na+, nesta célula, é muito lenta

b) A ativação dos canais para K+ é muito lenta

c) Outros canais dependentes de voltagem para Ca2+, intervêm prolongando a despolarização

d) O potencial de ação depende para a despolarização completamente de canais para Ca2+ de tipo L, cuja probabilidade de abertura aumenta quando a célula é muito despolarizada. Está célula não expressa canais para Na+ dependentes de voltagem

e) A densidade dos canais para K+ dependentes de voltagem nestas células é baixa

## Gabarito

**A** — A inativação LENTA de canais Na+ explicaria uma repolarização prolongada (porque Na+ continuaria entrando), mas NÃO explicaria uma despolarização rápida. De fato, inativação lenta de Na+ retardaria a despolarização inicial. Portanto, está é a resposta INCORRETA para explicar o fenótipo observado.

## Justificativa das alternativas corretas

b) Ativação lenta de K+ → repolarização lenta (correto)

c) Ca2+ channels → despolarização prolongada (correto)

d) Ausência de Na+ channels + Ca2+ L-type → despolarização lenta inicialmente, mas com platô prolongado (parcialmente correto)

e) Densidade baixa de K+ channels → repolarização lenta (correto)
