## Enunciado

Uma célula apresenta as seguintes concentrações iônicas:

| Íon | Intracelular (mM) | Extracelular (mM) |
|-----|-------------------|-------------------|
| K⁺  | 140               | 5                 |
| Na⁺ | 12                | 145               |
| Cl⁻ | 4                 | 110               |

Sabendo que a permeabilidade relativa é P_K : P_Na : P_Cl = 1 : 0,04 : 0,45, qual é o potencial de membrana aproximadamente?

## Alternativas

(A) -50 mV

(B) -70 mV

(C) 0 mV

(D) +30 mV

(E) +100 mV

## Gabarito

B

## Justificativa

Usando a **equação de Goldman-Hodgkin-Katz (GHK)**:

V_m = (RT/F) × ln[P_K[K⁺]_out + P_Na[Na⁺]_out + P_Cl[Cl⁻]_in / P_K[K⁺]_in + P_Na[Na⁺]_in + P_Cl[Cl⁻]_out]

Com permeabilidades relativas (normalizadas a P_K = 1):
- Numerador: 1(5) + 0,04(145) + 0,45(4) = 5 + 5,8 + 1,8 = 12,6
- Denominador: 1(140) + 0,04(12) + 0,45(110) = 140 + 0,48 + 49,5 = 189,98

V_m = 61 mV × log(12,6/189,98)
V_m = 61 mV × log(0,0663)
V_m = 61 mV × (-1,178)
V_m ≈ **-72 mV** (aproximadamente **-70 mV**)

Este valor concorda bem com o potencial de repouso fisiológico de neurônios (~-70 mV).
