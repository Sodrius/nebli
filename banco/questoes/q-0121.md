O limiar para o potencial de ação em um axônio, no qual há apenas canais para Na+ e para K+ sensíveis a voltagem, além dos canais ativos no potencial de repouso (Kir, K2P, etc), é o valor do potencial de membrana de uma célula excitável no qual:

## Alternativas

(A) Todos os canais para Na+ e para K+ se abrem com cinéticas aproximadamente iguais, porém como a diferença de potencial eletroquímico para o Na+ é maior, a corrente de Na+ supera a de K+, com o que ocorre o disparo de um potencial de ação

(B) Todos os canais dependentes de voltagem se abrem, com cinéticas obviamente diferentes, o canal para Na+ mais rapidamente que o canal para K+

(C) Os canais para Na+ se recuperam rapidamente da inativação e por eles passa uma corrente que supera as correntes dos demais íons, com disparo do potencial de ação

(D) Os canais do tipo Kir têm a sua condutância reduzida (retificadores para dentro) e a condutância dos canais para Na+, mesmo sem o aumento da probabilidade do estado aberto, permite uma corrente para dentro que supera todas as demais

(E) Nenhuma das alternativas

A

## Justificativa

No limiar, a despeolarização abre canais Na+ e K+ voltagem-dependentes. A cinética de Na+ é rápida (ativação), K+ lenta (ativação). No limiar específico, a força motriz eletroquímica para Na+ (Vm - ENa, onde Vm ~ -55mV, ENa ~ +60mV) é maior que para K+ (Vm - EK). Logo, mesmo com condutâncias similares momentaneamente, INa > IK, gerando corrente inward que despolariza mais, abrindo mais canais Na+ (feedback positivo) → PA.

## Conceitos-chave

- Potencial eletroquímico (driving force)
- Balanço de correntes no limiar
- Feedback positivo de Na+
