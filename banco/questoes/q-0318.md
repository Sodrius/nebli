## Enunciado

Descreva as regulações dos operons Lac e Trp em células procariontes.

## Gabarito

Ver Explicação abaixo.

## Explicação

OPERON LAC (CATABOLICO, INDUZIVEL): controla utilização de lactose. Estrutura: gene I (repressor LacI) — promotor (com sitio CAP) — operador lacO — genes estruturais lacZ (beta-galactosidase), lacY (permease), lacA (transacetilase). Regulação NEGATIVA: LacI ligado ao operador bloqueia RNA-pol. Inducao por LACTOSE: lactose -> alolactose -> liga LacI -> conformação muda -> LacI solta o operador -> transcrição. Regulação POSITIVA por CAP-cAMP (catabolite repression): CAP liga upstream so quando cAMP está ALTO. Glicose presente -> cAMP BAIXO (via fosfotransferase, EIIA-P inibe adenilato-ciclase) -> CAP não recruta RNA-pol -> transcrição basal. So lactose sem glicose -> cAMP alto, CAP ativo -> transcrição MAXIMA. OPERON TRP (ANABOLICO, REPRESSIVEL): controla biossintese de triptofano. Estrutura: promotor + operador + sequência lider trpL (atenuador) + genes estruturais trpE, trpD, trpC, trpB, trpA. Regulação NEGATIVA: repressor TrpR está INATIVO sem triptofano; quando ha Trp em excesso, Trp liga TrpR como CO-REPRESSOR -> ativa TrpR -> liga operador -> bloqueia transcrição. (Logica oposta ao lac: substrato ATIVA o repressor em vez de desativar.) ATENUACAO (mecanismo segundo nível): a sequência trpL codifica peptídeo lider com 2 codons Trp consecutivos; o ribossomo traduz simultaneamente a transcrição (acoplamento em procariotos). Se Trp e ABUNDANTE, ribossomo passa rápido nesses codons -> hairpin TERMINADOR se forma -> transcrição para precocemente. Se Trp e ESCASSO, ribossomo pausa nos codons Trp (esperando trp-tRNA) -> hairpin ANTITERMINADOR se forma -> RNA-pol continua transcrevendo os genes estruturais. RESUMO: Lac = catabolico, lactose desativa repressor LacI (libera transcrição). Trp = anabolico, Trp ativa repressor TrpR (bloqueia transcrição) + atenuacao por ribossomo.
