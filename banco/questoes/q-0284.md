## Enunciado

Um estudante inexperiente preparou soluções estoque de antimicina e oligomicina, mas esqueceu de rotular os frascos das soluções. Ele possui uma suspensao de mitocôndrias respirando na presença de succinato, um eletrodo de oxigênio (oxigrafo) e soluções estoque (que podem ser adicionadas as mitocôndrias) de ADP, fosfato inorgânico e dinitrofenol. Planeje um experimento em que seja possivel diferenciar os frascos contendo antimicina e oligomicina, explicando como sera feita essa diferenciacao. Esquematize os efeitos de cada adicao planejada sobre a concentração de oxigênio na suspensao mitocondrial. Justifique os efeitos observados detalhando os mecanismos de regulação envolvidos.

## Explicação

PROTOCOLO: mitocôndrias + succinato + Pi (estado 4 — respiração basal lenta, gradiente alto). 1) Adicionar ADP -> entra no estado 3 (queda rápida de O2): ATP-sintase consome o gradiente, cadeia desbloqueia, succinato-DH (complexo II) doa elétrons via FADH2 -> Q -> III -> IV -> O2. 2) Aguardar consumo do ADP -> volta estado 4. 3) Adicionar a primeira solução incognita. SE FOR OLIGOMICINA: bloqueia ATP-sintase (Fo) -> gradiente não dissipa -> cadeia para por contra-pressão -> consumo de O2 cessa (plateau). Para confirmar: adicionar DINITROFENOL (desacoplador) -> dissipa o gradiente sem ATP -> cadeia desbloqueia -> consumo de O2 retoma (queda na curva). SE FOR ANTIMICINA: bloqueia complexo III (sitio Qi do cyt b) -> elétrons do FADH2 não passam de QH2 para citocromo c -> cadeia para downstream do bloqueio -> O2 cessa. DNP Não restaura (problema e transferencia de elétrons, não gradiente) -> O2 permanece estável. DIFERENCIACAO: o frasco cuja inibição e REVERTIDA por DNP e oligomicina; o que Não e revertida e antimicina.
