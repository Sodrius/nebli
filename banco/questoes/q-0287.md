## Enunciado

Animais de laboratorio foram submetidos a dietas compostas exclusivamente de carboidratos, ou lipídeos, ou proteínas. Estes tres tipos de nutrientes são necessários para a sobrevivencia. Não havendo outras restricoes na dieta, responder que grupo de animais sobreviveria, verificando se e possivel sintetizar: a) ácido graxo a partir de glicose; b) proteína a partir de glicose; c) glicose a partir de ácido graxo; d) proteína a partir de ácido graxo; e) glicose a partir de proteína; f) ácido graxo a partir de proteína. Justificar suas respostas, indicando a via quando possivel ou a razao da impossibilidade.

## Gabarito

Ver Explicação abaixo.

## Explicação

a) AG a partir de glicose: SIM. Glicose -> piruvato (glicolise) -> acetil-CoA (PDH) -> citrato (mitocôndria) -> sai p/ citosol -> ATP-citrato-liase regenera acetil-CoA citosolico -> ACC -> malonil-CoA -> síntese de AG pela ácido-graxo-sintase. NADPH vem da via das pentoses. b) Proteína a partir de glicose: SIM, mas APENAS aminoácidos Não-essenciais. Glicose -> intermediários glicoliticos/Krebs (piruvato, 3-PG, OAA, alfa-KG) -> transaminacao com glutamato -> Ala, Ser, Asp, Glu, Gln, Pro, Gly. Não sintetiza Lys, Leu, Ile, Val, Met, Thr, Phe, Trp, His (essenciais — sem dieta proteica o animal morre por falta destes). c) Glicose a partir de AG: Não em mamiferos (regra fundamental). Beta-oxidação gera acetil-CoA, mas a PDH e IRREVERSÍVEL e não ha reversao acetil -> piruvato. Em mamiferos, falta o ciclo do glioxilato (presente em plantas/bacterias) que permitiria isso. EXCECAO didatica: AG impares geram propionil-CoA -> succinil-CoA -> OAA -> gliconeogênese (mas saldo minimo, so o C3 final). Glicerol da hidrolise de triacilglicerois VIRA glicose (mas e o glicerol, não o AG). d) Proteína a partir de AG: Não. Apenas o 1-3% de C3 dos AG impares (via propionil) pode ir a OAA -> alfa-KG e gerar AA não-essenciais. Mas o grosso dos AG (cadeia par) so vira acetil-CoA — não sintetiza nenhum AA porque acetil-CoA não gera OAA liquido (entra e sai do Krebs como CO2). Sem AA essenciais (da dieta) não ha síntese proteica completa -> animal morre. e) Glicose a partir de proteína: SIM. AA glicogenicos (Ala, Asp, Glu, Gly, Ser, Cys, Met, Val, Pro, His, Arg, Phe parcial, Tyr parcial, Thr, Ile parcial) -> piruvato/Krebs/OAA -> gliconeogênese hepática/renal. Apenas Leu e Lys são puramente cetogenicos. f) AG a partir de proteína: SIM. AA cetogenicos/mistos (Leu, Lys, Phe, Tyr, Trp, Ile) -> acetil-CoA/acetoacetil-CoA -> lipogenese. AA glicogenicos -> piruvato -> acetil-CoA -> AG. CONCLUSÃO: grupo dieta SO carboidrato morre (falta AA essenciais e AGE). SO lipídeo morre (falta glicose obrigatória p/ hemacia/SNC, e falta AA essenciais). SO proteína sobrevive em princípio (pode fazer glicose por gliconeogênese e AG por lipogenese), exceto AGE (omega-3/6).
