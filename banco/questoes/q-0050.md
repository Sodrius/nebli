## Enunciado

Entre as alternativas abaixo uma só não é requisito, pois está errada, para o disparo do potencial de ação em um axônio:

## Alternativas

(A) Ativação rápida e inativação dos canais para Na+
(B) Ativação lenta e desativação dos canais para K+
(C) Repolarização por um tempo suficiente para resgatar os canais para K+ do estado inativado
(D) Repolarização por um tempo suficiente para resgatar os canais para Na+ do estado inativado
(E) Estímulo despolarizante que abra canais para Na+ em número suficiente para que a corrente para dentro, de Na+, exceda as correntes para fora

## Gabarito

C

## Explicação

O disparo de um potencial de ação exige mecanismos moleculares muito específicos envolvendo a cinética dos canais iônicos. A alternativa C está incorreta porque confunde o papel funcional dos canais de K+. Os canais para K+ dependentes de voltagem NÃO sofrem inativação rápida típica — em vez disso, continuam abertos durante todo o plato de despolarização. O que importa não é "resgatar K+ da inativação", mas sim sua **ativação lenta** (alternativa B), que permite que o K+ saia durante a repolarização. Os canais para Na+ dependem de recuperação da inativação (alternativa D) para disparar um novo PA. A alternativa A descreve as cinéticas rápidas (ativação/inativação) essenciais para o Na+. A alternativa E resume o princípio fundamental: quando influxo de Na+ > efluxo de K+, o potencial despolariza até o limiar. A alternativa C traz um conceito invertido e fisiologicamente incorreto, tornando-a a resposta errada.
