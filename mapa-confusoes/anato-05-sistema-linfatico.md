# Mapa de Confusões — Sistema Linfático (Anatomia)

Slug: `anato-05-sistema-linfatico`. Semente das distratoras da E2. ≥4 confusões por subtópico.

## 1.1 Funções

1. **Circuito fechado** — achar que o linfático faz alça de ida e volta como o sanguíneo. Erro: é via de mão única, aberta no tecido, que desagua na veia. (interna: slide-04)
2. **Sangue → linfa** — achar que a linfa é filtrada a partir do sangue arterial diretamente. Erro: a linfa vem do líquido *intersticial*, a sobra da filtração capilar.
3. **Gordura no sangue** — supor que a gordura da dieta cai direto no capilar sanguíneo do intestino. Erro: entra no vaso lactífero (linfático) como quilo.
4. **Só drenagem** — reduzir o linfático a um dreno. Erro: também transporta gordura e faz vigilância imune.

## 1.2 / 1.3 Elementos e capilar

1. **Entrada por pressão** — achar que a linfa é empurrada para dentro do capilar. Erro: as células sobrepostas abrem quando os filamentos de fixação tracionam com o inchaço; a pressão interna FECHA a saída.
2. **Membrana basal presente** — supor que o capilar linfático é selado como o sanguíneo. Erro: membrana basal ausente/descontínua → mais permeável.
3. **Tudo tem linfático** — achar que todo tecido drena por linfa. Erro: cartilagem, epiderme, córnea, SNC, partes do baço/medula/osso são avasculares para o linfático.
4. **Capilar linfático atravessa** — imaginá-lo como tubo passante. Erro: começa em fundo cego (dedo de luva).

## 2.1 Órgãos primários

1. **Timo fabrica** — achar que o timo produz linfócitos. Erro: o timo *amadurece* os T; a produção é na medula óssea.
2. **Baço primário** — classificar o baço como primário. Erro: é secundário (resposta imune, filtra sangue).
3. **Linfonodo primário** — achar que linfócito nasce no linfonodo. Erro: linfonodo é secundário; nascimento/maturação é medula/timo.
4. **Primário = maior** — confundir "primário" com "principal/maior". Erro: primário = onde nasce/amadurece sem antígeno.

## 2.2 Linfonodo

1. **Aferente = eferente** — achar que entra e sai um vaso igual. Erro: vários aferentes entram pela convexidade, um (poucos) eferente sai pelo hilo.
2. **Fluxo rápido** — supor que a linfa atravessa depressa. Erro: o estrangulamento a faz passar devagar — é o tempo de filtragem.
3. **Eferente entra** — inverter aferente/eferente. Erro: aferente traz para dentro, eferente leva para fora (pelo hilo).
4. **Filtra sangue** — achar que o linfonodo filtra sangue. Erro: filtra *linfa*; quem filtra sangue é o baço.

## 2.3 Cadeias e baço

1. **Baço tem aferente linfático** — achar que o baço recebe linfa. Erro: o baço filtra o sangue, não recebe vaso aferente de linfa.
2. **Mama → inguinal** — errar o destino da drenagem mamária. Erro: a mama drena principalmente para a axila.
3. **Cadeia drena qualquer região** — ignorar territórios. Erro: cada cadeia drena um território definido (pé→inguinal; mão→epitroclear/axilar).
4. **Baço menor** — achar o baço um órgão linfoide pequeno. Erro: é o MAIOR órgão linfoide.

## 2.4 MALT

1. **MALT é órgão encapsulado** — achar o MALT um órgão com cápsula. Erro: é tecido linfoide difuso na mucosa.
2. **Placa de Peyer no cólon** — localizar as placas de Peyer no intestino grosso. Erro: íleo (delgado) e apêndice.
3. **Anel de Waldeyer só palatina** — reduzir o anel às tonsilas palatinas. Erro: faríngea + palatinas + tubárias + linguais.
4. **Tonsila = linfonodo** — igualar tonsila a linfonodo. Erro: tonsila é MALT concentrado, sem os aferentes/eferentes do linfonodo.

## 3.1 Propulsão

1. **Coração linfático** — supor uma bomba central. Erro: não há; move por musc. lisa da parede + bomba muscular + bomba respiratória.
2. **Sem válvulas** — achar o vaso linfático liso por dentro. Erro: válvulas numerosas (mais que nas veias) garantem o sentido único.
3. **Bomba respiratória empurra por igual** — ignorar o jogo de pressões. Erro: inspiração baixa a pressão torácica e sobe a abdominal → suga a linfa para cima.
4. **Gravidade ajuda** — achar que a linfa desce fácil. Erro: sobe contra a gravidade, por isso precisa de válvulas + bombas.

## 3.2 / 3.3 Troncos e ductos

1. **Ducto torácico drena tudo** — esquecer a exceção. Erro: drena tudo MENOS o quadrante superior direito (esse vai no ducto linfático direito).
2. **Cisterna do quilo no pescoço** — localizá-la em cima. Erro: é a base dilatada do ducto torácico, no abdome (L2), recebe lombares + intestinal.
3. **Dois ductos simétricos** — achar que cada ducto drena metade. Erro: torácico drena ~3/4 do corpo; direito só o quadrante sup. D.
4. **Ducto desemboca na artéria** — achar que a linfa volta pela artéria. Erro: volta no ângulo venoso (subclávia + jugular interna).
5. **Tronco = ducto** — confundir troncos com ductos. Erro: 5 pares de troncos regionais confluem para 2 ductos.
