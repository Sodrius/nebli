# Mapa de Integração — anato-03-articulacoes
# Gate: cada Q11-Q25 precisa cruzar dois domínios distintos (campo A + campo B)

Q11 conecta [classificação estrutural (fibrosa/cartilagínea/sinovial)] + [classificação funcional (sinartrose/anfiartrose/diartrose)]
Q12 conecta [sutura craniana (fechamento progressivo, sinostose)] + [desenvolvimento do crânio / craniossinostose]
Q13 conecta [lâmina epifisial (sincondrose transitória)] + [crescimento ósseo longitudinal]
Q14 conecta [cartilagem articular (avascular)] + [mecanismo de nutrição por difusão do líquido sinovial]
Q15 conecta [membrana sinovial (vascularização + produção de líquido)] + [sinovite / resposta inflamatória articular]
Q16 conecta [tipos de articulação sinovial (geometria das superfícies)] + [eixos de movimento / biomecânica]
Q17 conecta [Lei de Hilton (nervo compartilhado: músculo + articulação + pele)] + [bloqueio anestésico regional / dor referida]
Q18 conecta [gonfose (sindesmose, fibrosa)] + [vascularização excepcional do ligamento periodontal]
Q19 conecta [sinostose (ossificação do tecido intermediário)] + [lâmina epifisial / término do crescimento longitudinal]
Q20 conecta [cartilagem articular avascular (sem regeneração)] + [patogênese da artrose / progressão degenerativa]
Q21 conecta [lábio articular (aumenta congruência)] + [estabilidade vs mobilidade da articulação esferóide (ombro)]
Q22 conecta [entorse (ligamento lesado, sem luxação)] + [diferenciação entre estruturas lesadas: ligamento vs tendão vs osso]
Q23 conecta [tipos sinoviais uniaxiais (gínglimo vs trocóide)] + [diferença de eixo de rotação e plano de movimento]
Q24 conecta [articulação selar carpometacárpica do polegar] + [oposição do polegar / preensão de precisão]
Q25 conecta [bursas sinoviais (proteção de tendões durante movimento)] + [bursite / inflamação por uso repetitivo]
