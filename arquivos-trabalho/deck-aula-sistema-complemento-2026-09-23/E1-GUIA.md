## Sequência sugerida

1. **Lógica geral (slides 2–7):** zimogênios clivados em fragmento "a" (solúvel) e "b" (que se liga à superfície); convertases; três fases (reconhecimento → enzimática → efetora).
2. **Via clássica (8–20):** C1q liga Fc (≥2 IgG ou 1 IgM); C1r → C1s cliva C4 e C2 → C4b2a (C3 convertase) → C4b2a3b (C5 convertase).
3. **Via alternativa (21–23):** hidrólise espontânea de C3; fator B + fator D → C3bBb; properdina estabiliza; alça de amplificação; C3bBb3b.
4. **Via das lectinas (28–30):** MBL + MASP-1/2, análogos de C1q/C1r/C1s; mesma convertase da clássica.
5. **MAC (24–27, 34):** C5b-C6-C7-C8-poli-C9, lise osmótica.
6. **Funções e receptores (31–46):** opsonização (C3b/iC3b via CR1/CR3), anafilatoxinas (C3a, C4a, C5a), quimiotaxia (C5a), remoção de imunocomplexos (CR1 das hemácias), correceptor B (C3d–CR2).
7. **Regulação (47–53):** C1-INH, fator I com cofator H, DAF/CD55, CD59.
8. **Deficiências (54–59):** C1q/C2/C4 → LES; C3 → piogênicas; C5–C9 → *Neisseria*; fator H/I → consumo de C3, piogênicas, SHU atípica; C1-INH → angioedema hereditário; CD59 → HPN.
9. **Aplicação (prova):** CH50 avalia via clássica; AH50, via alternativa. C3 baixo com C4 normal → consumo pela alternativa.
