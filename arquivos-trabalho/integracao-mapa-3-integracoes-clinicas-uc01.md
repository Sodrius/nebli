# Filtro de admissão Q13–Q24 — Integração (intra-caso)

Cruzamento é **intra-caso** (decisão Davi 2026-06-08). Formato: `Qxx (PARTE N) conecta [subtópico A] + [subtópico B]`.

## PARTE I (lipídeos via SDR) — Q13, Q14, Q15, Q16

- Q13 (PARTE I) conecta [estrutura anfipática do fosfolipídeo] + [orientação na interface ar-água].
- Q14 (PARTE I) conecta [Lei de LaPlace P=2T/R] + [variação de T com surfactante presente].
- Q15 (PARTE I) conecta [maturação do pneumócito tipo II] + [janela terapêutica do corticoide antenatal].
- Q16 (PARTE I) conecta [tensão superficial alveolar] + [complacência pulmonar e esforço respiratório].

## PARTE II (proteínas via Alzheimer) — Q17, Q18, Q19, Q20

- Q17 (PARTE II) conecta [efeito hidrofóbico no dobramento] + [exposição de face hidrofóbica em proteína mal-dobrada].
- Q18 (PARTE II) conecta [β-folha intermolecular] + [crescimento progressivo do agregado].
- Q19 (PARTE II) conecta [compartimentalização dos dois agregados (Aβ × tau)] + [consequências funcionais distintas].
- Q20 (PARTE II) conecta [perda de neurônios colinérgicos do núcleo basal] + [mecanismo de ação do anticolinesterásico].
